# Compatibility references

ChatGPT's web history endpoints are private, undocumented interfaces. Public implementations were consulted to understand endpoint shapes, active-branch metadata and pagination:

- [ChatGPT Copy Entire Chat — API-first history retrieval notes](https://github.com/sguzman/script-monkey/blob/main/userscripts/chatgpt.com/chatgpt-copy-entire-chat/README.md)
- [ChatGPT Conversation Table of Contents — message hooks and history pagination](https://github.com/TacticalOriental/ChatGPT_Conversation_Table_of_Contents)

This repository contains a separately implemented minimal extension. The references above are not runtime dependencies. See [Chrome's official extension installation guide](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) for developer-mode installation.

The preview image and automated tests use synthetic conversations. The icon was generated programmatically for this project.
